# Todo App - MERN Stack

A simple Todo application built using the MERN stack. This project was created to practice building a full-stack application using React, Node.js, Express, and MongoDB.

## Tech Stack

- React.js
- Node.js
- Express.js
- MongoDB
- CSS

## Features

- Add new todos
- View todos
- Edit todos
- Delete todos
- Mark todos as completed
- Store todos in MongoDB
- REST API for todo operations
